## 上线闸门

只有同时满足以下条件，才能把真实购买开关设为启用：

1. OD-01 至 OD-06 已关闭并留有配置/审批证据；
2. Source Catalog 与报告模板已通过教研抽检；
3. 自动化测试、数据库迁移和安全扫描全部通过；
4. 微信开发者工具预览及 iOS/Android 真机检查通过；
5. 正常支付、取消、回调延迟、主动查单、重复通知和退款完成受控测试；
6. 运维人员能够执行查单、对账、告警和密钥轮换手册；
7. 产品界面没有把 Mock、演示事实或前端回调显示为真实支付成功。

满足上述条件并形成发布审批记录后，授权发布人才能把 `PAID_COMPASS_ENABLED` 设为 `true`。紧急回滚先恢复为 `false`；该操作只阻止新的创单/预支付，不能取消已发支付参数或拒绝可信成功的在途交易。若回滚原因是Source Catalog撤回，受影响交易必须进入人工事故、退款、通知/查退款补偿和审计流程。

OpenAI Agent使用独立闸门。只有OD-05、OD-06、OD-12、OD-15关闭，并且Agent自动化、预发布真实API、未成年人/PII、删除和故障隔离清单留证后，授权发布人才能依次部署独立worker并开启`OPENAI_AGENT_ENABLED/AI_WORKER_ENABLED`。Agent紧急回滚只关闭Agent与worker，不关闭支付、飞书或已购报告/PDF；不自动执行生产down migration。
