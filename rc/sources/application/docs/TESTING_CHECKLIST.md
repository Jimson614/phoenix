# Phoenix Compass™ Free MVP｜测试清单

## 发布阻断项

- [ ] 正式 Logo 文件未被重绘或替换；色值与品牌基线一致。
- [ ] Landing 主 CTA 文案为“开始30秒成长探索”。
- [ ] 7 字段分 5 屏完成；可返回、修改、刷新恢复。
- [ ] 兴趣最多 2 项；“尚在探索”与其他兴趣互斥。
- [ ] 身份选择“不愿透露”或不选择时仍可完成。
- [ ] API 拒绝额外字段与不合法 code，不接受姓名、学校、电话、成绩等 PII。
- [ ] 合法结果包含 1 个成长类型、3 个优势信号、2–3 个方向、1 个今天行动与免责声明。
- [ ] AI 无密钥、网络错误、超时、拒绝、非法 JSON 与缺字段时均返回安全模板。
- [ ] AI Prompt、JSON Schema、运行时校验和结果 UI 均不包含产品、价格、支付 CTA 或购买链接。
- [ ] 模型若返回额外商业字段，运行时校验拒绝该结果并回退到安全模板。
- [ ] 375 / 390 / 430 px 宽度无横向滚动；点击目标 ≥44 px；键盘焦点清楚。
- [ ] 不出现心理诊断、医疗建议、职业适配结论、录取概率、保证或身份价值判断。

## 功能与异常

- [ ] 单选课程后自动进入下一屏；双问题/多选屏使用明确“下一步”。
- [ ] 返回修改后最终提交使用最新答案。
- [ ] 重复点击提交不会产生重复请求。
- [ ] 提交后立即显示生成等待态，不显示虚假百分比。
- [ ] 结果缺失或会话失效时显示可恢复的空状态。
- [ ] 1–5 分反馈只能提交一次并显示成功反馈。
- [ ] 结果页在“今天行动”后直接进入反馈，不出现购买路径。

## 分析事件

- [ ] `free_compass_viewed`
- [ ] `free_compass_started`
- [ ] `free_compass_completed`
- [ ] `free_compass_result_viewed`
- [ ] `result_helpfulness_submitted`
- [ ] 同一流程关键事件不重复；事件无姓名、手机号、学校名、证件号或身份用户属性。

## 自动化命令

- [ ] `pnpm lint`
- [ ] `pnpm typecheck`
- [ ] `pnpm test`
- [ ] `pnpm build`

## AI 金标建议

上线前补齐至少 20 组金标输入，覆盖年龄、地区、课程、单/双兴趣、“尚在探索”与全部家庭目标。特别检查香港身份与内地课程、医疗兴趣、艺术兴趣、年龄年级不常见、身份不透露，以及模型尝试输出产品推荐、价格、支付或购买链接的越界场景。
